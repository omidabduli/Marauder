Team workload board · Python & Flask

See who has room before the next task goes out.

Marauder is a traffic-light board for teams. Everyone marks how loaded they are for the current two weeks, so whoever hands out work can see who has capacity and who needs relief.

Four statuses

One honest signal per person

Each status has its own shape as well as its own colour, so the board still reads on a grey printout or for someone who can't tell red from green.

Load ranges are the rule of thumb from the built-in help. Regular overtime or deadlines at risk always count as red.

How it works

Small enough to run on one office PC

A Flask server, two HTML pages and a CSV file. Nothing to install on the clients; colleagues open the address in a browser.

Two-week periods

Each column is a pair of calendar weeks. The current pair is marked and one future pair is shown by default. When a new period starts, everyone carries over their last status until they change it.

You edit your own row

Choose your name, then click a cell to move through Green, Yellow, Orange and Red. Changes are saved at once, and other open boards pick them up within 30 seconds.

Admin settings

Behind a password at /admin: the language, whether past weeks can still be edited and how far back, how many future periods to show, and the password itself.

One file of data

People and statuses live in users.csv. The server adds a column for each new week and keeps the most recent 16, so the file never grows without limit.

Help built in

30 questions and answers from ampel_faq.csv, searchable from the board. For example: which colour to choose with three large projects, or when working part-time. Written in German.

Four languages

The interface switches between German, English, French and Italian from the admin page. Names, groups and help texts stay as entered.

Run it

On your own machine

Needs Python 3.7 or newer. The demo on this page runs without a server; the real board needs one so the team shares the same data.

$ git clone https://github.com/omidabduli/Marauder.git
$ cd Marauder
$ pip install -r requirements.txt
$ python server.py
  1. Open http://localhost:5005. Colleagues on the same network use the address the server prints at start-up.
  2. On macOS or Windows you can double-click RUN_MARAUDER.command or RUN_MARAUDER.bat instead. Both set up a virtual environment first.
  3. The admin password starts as admin. Change it on the admin page before the team uses the board.
